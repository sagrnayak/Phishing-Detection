# Phishing Email Detection Model

A machine learning model that detects phishing emails using NLP.

## Features
- Text preprocessing
- TF-IDF feature extraction
- Logistic Regression classifier
- Accuracy & confusion matrix

## How to Run
pip install -r requirements.txt
python phishing_model.py

## Output
- Classification: Phishing or Safe
- Accuracy score
- Confusion matrix

## Disclaimer
Dataset is small for demo. Use real datasets for production.
